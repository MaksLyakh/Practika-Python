# Лабораторная работа №9

## Тема: Сетевое взаимодействие в Python

**Вариант 15 — Страхование**

## Цель работы

Разработать клиент-серверное приложение на Python с использованием TCP-сокетов, JSON-протокола, многопоточности и модульного тестирования.

## Описание проекта

Программа представляет собой систему управления страховыми полисами.

TCP-сервер принимает запросы клиентов, обрабатывает команды и возвращает результаты в формате JSON.

Клиенты взаимодействуют с сервером через консольное меню. Поддерживается одновременное подключение нескольких клиентов.

## Возможности программы

1. Создание страхового полиса.
2. Получение полиса по ID.
3. Получение всех страховых полисов.
4. Изменение статуса полиса.
5. Удаление полиса.
6. Поиск полисов по имени клиента.
7. Расчёт стоимости страхового полиса.

## Архитектура приложения

- `models.py` — модель страхового полиса и перечисление статусов.
- `exceptions.py` — пользовательские исключения.

Архитектура разделяет сетевое взаимодействие, бизнес-логику и хранение данных.

## Запуск программы

### 1. Запуск сервера

Открыть терминал в корне проекта и выполнить:

    python server.py

Сервер работает по адресу `127.0.0.1:5000`.

### 2. Запуск клиента

В другом терминале выполнить:

    python client.py

После подключения появится консольное меню.

### 3. Проверка нескольких клиентов

Открыть три отдельных терминала и в каждом выполнить:

    python client.py

Все клиенты работают с общим хранилищем страховых полисов.

## Формат обмена данными

Для передачи сообщений используется JSON Lines: каждое JSON-сообщение завершается символом новой строки.

Запрос содержит два основных поля:

- `command` — название команды.
- `data` — параметры команды.

### Пример создания полиса

    {
      "command": "create_policy",
      "data": {
        "policy_id": 1,
        "client_name": "Иван Иванов",
        "insurance_type": "Авто",
        "amount": 500000,
        "duration_months": 12
      }
    }

### Пример успешного ответа

    {
      "status": "success",
      "data": {
        "id": 1,
        "client_name": "Иван Иванов",
        "insurance_type": "Авто",
        "amount": 500000,
        "duration_months": 12,
        "status": "Активен"
      }
    }

### Пример ошибки

    {
      "status": "error",
      "error": "Полис с ID 999 не найден"
    }

## Расчёт стоимости страхования

В учебной реализации применяется годовой тариф 5%.

Формула:

    Стоимость = Страховая сумма × 0.05 × Срок / 12

Пример:

- Страховая сумма: 500 000 руб.
- Срок: 12 месяцев.
- Годовой тариф: 5%.
- Стоимость страхования: 25 000 руб.

### JSON-запрос расчёта

    {
      "command": "calculate_cost",
      "data": {
        "policy_id": 1
      }
    }

## Обработка ошибок

Программа обрабатывает:

- Некорректные данные страховых полисов.
- Отсутствующие и повторяющиеся ID.
- Неизвестные команды.
- Некорректные JSON-сообщения.
- Ошибки сетевого соединения.
- Превышение времени ожидания.
- Превышение допустимого размера сообщения.

## Многопоточность

Каждый подключённый клиент обслуживается отдельным потоком.

Для синхронизации доступа к общему хранилищу используется `threading.RLock`.

Сервер ведёт журнал подключений, выполненных команд и ошибок.

Для запуска всех тестов:

## Особенности реализации

- Поддерживается несколько одновременных TCP-клиентов.
- Используется JSON-протокол с разделением сообщений.
- Для сетевых операций предусмотрены тайм-ауты.
- Реализована обработка пользовательских исключений.
- Данные хранятся в оперативной памяти сервера.
- После перезапуска сервера полисы не сохраняются.
