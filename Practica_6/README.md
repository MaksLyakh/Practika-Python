
# Лабораторная работа №6

**Тема:** Декораторы, контекстные менеджеры и расширенные возможности Python.

**Вариант 15:** Медицинская клиника.

## Описание программы

Консольное приложение для управления пациентами, врачами и приёмами медицинской клиники.

## Функциональные возможности

- Добавление, удаление и поиск пациентов, врачей и приёмов.
- Просмотр всех объектов.
- Изменение статуса приёма.
- Подсчёт количества приёмов определённого врача.
- Расчёт средней продолжительности приёма.
- Формирование статистики.
- Обработка ошибок пользовательского ввода.
- Демонстрация декораторов, контекстного менеджера, Protocol и интроспекции.

## Структура проекта

- `main.py` — главное меню программы.
- `models.py` — классы пациентов, врачей и приёмов.
- `services.py` — основная логика приложения.
- `decorators.py` — пользовательские декораторы.
- `context.py` — контекстный менеджер.
- `protocols.py` — описание Protocol.
- `README.md` — документация проекта.

## Используемые технологии

- Python 3.10+
- dataclass
- Enum
- Декораторы и functools.wraps
- Контекстные менеджеры
- Protocol
- Интроспекция объектов
- Аннотации типов

Сторонние библиотеки не требуются.

## Запуск программы

Открыть терминал в папке проекта и выполнить:

```bash
python main.py
```

После запуска появится консольное меню для работы с медицинской клиникой.

## Хранение данных

Данные хранятся в оперативной памяти и удаляются после завершения программы.
