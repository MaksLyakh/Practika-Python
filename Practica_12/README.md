# Лабораторная работа №12 - Вариант 15 - Аптека

Учебное консольное приложение на SQLAlchemy 2.x и PostgreSQL. Структура: модели -> Repository -> Service -> консольное меню.

## Что реализовано

- 4 таблицы: customers, medicines, purchases, purchase_items; PK/FK/NOT NULL/UNIQUE/CHECK.
- Связи 1:N и M:N (покупки и лекарства через purchase_items).
- CRUD, поиск, фильтрация с двумя условиями, сортировка, связанные покупки.
- Покупка нескольких лекарств с расчётом стоимости, блокировкой остатков и откатом при ошибке.
- Отмена покупки с возвратом остатков.
- Дополнительно: Alembic, пагинация, COUNT/SUM/AVG/MIN/MAX, M:N, AsyncSession, Docker Compose, pytest.

## 1. Сначала проверьте программы (CachyOS KDE, fish)

```fish
python --version
python -m pip --version
podman --version
docker --version
docker compose version
psql --version
```

Достаточно **Docker Compose ИЛИ локального PostgreSQL**. Podman необязателен. Если docker отсутствует, можно использовать локально установленный PostgreSQL. Не устанавливайте всё сразу - сначала посмотрите вывод команд.

## 2. Установка зависимостей

Откройте терминал в папке проекта:

```fish
python -m venv .venv
source .venv/bin/activate.fish
python -m pip install -r requirements.txt
```

Создайте файл `.env` из `.env.example` (можно командой `cp .env.example .env`).

## 3. PostgreSQL

Если установлен Docker Compose:

```fish
docker compose up -d
docker compose ps
```

Порт 5432 должен быть свободен. Если уже работает локальный PostgreSQL, настройте `DATABASE_URL` в `.env` под его учётные данные.

## 4. Создание схемы и данных

```fish
alembic upgrade head
python -m app.seed
python -m app.main
```

**Важно:** `app.main` также вызывает `create_all` для удобства первого запуска, но для демонстрации дополнительного задания Alembic сначала используйте `alembic upgrade head` на чистой БД.

## 5. Дополнительные проверки

```fish
python -m pytest tests -v
python -m app.async_demo
alembic current
```

Тесты используют отдельную временную SQLite-базу, чтобы не изменять ваши данные в PostgreSQL.

## Файлы

- `app/models.py` - ORM-модели.
- `app/database.py` - подключение к СУБД.
- `app/repository.py` - ORM-запросы.
- `app/service.py` - проверка данных, транзакции.
- `app/main.py` - консольное меню.
- `app/seed.py` - демо-данные.
- `app/async_demo.py` - асинхронный SQLAlchemy.
- `migrations/` - Alembic.
- `tests/` - автоматические тесты.

## Вопросы для защиты

**ORM** связывает таблицы БД с Python-классами. **Session** управляет ORM-объектами и транзакцией. **Repository** отвечает за запросы, **Service** - за правила покупки. **commit** сохраняет изменения, **rollback** отменяет всю незавершённую транзакцию. **PurchaseItem** реализует M:N и хранит цену на момент покупки.
