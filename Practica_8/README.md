## 1. Цель работы

Изучить и применить паттерны проектирования Factory,
Strategy, Repository и Observer при разработке
программы на Python.

## 2. Описание программы

Программа предназначена для записи пациентов
на медицинские приёмы.

Реализованы следующие возможности:

- Создание записи на приём.
- Выбор пациента и врача.
- Выбор типа медицинской услуги.
- Расчёт стоимости по выбранному тарифу.
- Просмотр всех записей.
- Завершение медицинского приёма.
- Удаление записи.
- Уведомление о событиях.

## 3. Виды медицинских услуг

| Услуга | Базовая стоимость |
|---|---|
| Терапевтический приём | 1500 руб. |
| Диагностическая процедура | 2500 руб. |
| Консультация | 2000 руб. |

## 4. Виды стоимости

- Стандартная — базовая стоимость.
- Льготная — скидка 20%.
- Срочная — наценка 50%.

## 5. Реализованные паттерны

### Factory

Класс AppointmentFactory создаёт объекты
Appointment в зависимости от выбранного типа
медицинского приёма.

### Strategy

Классы StandardPricing, DiscountPricing
и UrgentPricing реализуют разные способы
расчёта стоимости медицинских услуг.

### Repository

Интерфейс AppointmentRepository описывает
операции хранения данных.

Класс MemoryAppointmentRepository реализует
хранение записей в оперативной памяти.

### Observer

Класс AppointmentNotifier уведомляет
подписанных наблюдателей о событиях.

ConsoleObserver выводит уведомления в консоль.

## 6. Дополнительные технологии

- dataclass — описание моделей данных.
- Enum — перечисление типов и статусов приёмов.
- Protocol — определение интерфейсов.
- unittest — автоматическое тестирование.

## 7. Структура проекта

- bad_version/ — первоначальная версия программы.
- factories/ — фабрика медицинских записей.
- interfaces/ — интерфейсы репозитория и стратегий.
- models/ — модели данных и перечисления.
- observers/ — система уведомлений.
- repositories/ — реализация хранилища.
- services/ — бизнес-логика клиники.
- strategies/ — расчёт стоимости.
- tests/ — автоматические тесты.
- ui/ — консольный интерфейс.
- main.py — точка входа в программу.

## 8. Запуск программы

Из корневой папки проекта выполнить:

    python main.py

Для запуска первоначальной версии:

    python bad_version/main.py

## 9. Запуск тестов

Выполнить команду:

    python -m unittest discover -s tests -v

В проекте предусмотрено 10 автоматических тестов.
