
# Практическая работа №7

## Тема
Рефакторинг программного кода с применением принципов SOLID.

## Вариант 15 — Медицинская клиника

### Цель работы
Изучить принципы SOLID и применить их при рефакторинге программы на языке Python.

## Описание программы

Программа предназначена для управления медицинской клиникой.

Основные возможности:
- Регистрация пациентов.
- Регистрация врачей.
- Запись пациентов на приём.
- Завершение медицинских приёмов.
- Просмотр списка приёмов.
- Получение результатов завершённых приёмов.
- Вывод уведомлений.

## Структура проекта

- `bad_version/main.py` — первоначальная версия программы.
- `models/` — классы пациентов, врачей и приёмов.
- `interfaces/` — абстрактные интерфейсы.
- `repositories/` — хранение данных.
- `services/` — основная логика приложения.
- `infrastructure/` — система уведомлений.
- `ui/` — консольный интерфейс.
- `main.py` — точка входа в исправленную программу.

## Применение SOLID

**SRP** — разделение ответственности между классами.

**OCP** — возможность расширения функциональности без изменения основной логики.

**LSP** — возможность использовать реализации вместо соответствующих абстракций.

**ISP** — разделение интерфейсов по назначению.

**DIP** — зависимость от абстракций, а не конкретных реализаций.

## Запуск программы

Для запуска исправленной версии:

```bash
python main.py
```

Для запуска первоначальной версии:

```bash
python bad_version/main.py
```

## Особенности

- Используется Python 3.10 или новее.
- Сторонние библиотеки не требуются.
- Данные хранятся в оперативной памяти.
- После завершения программы данные не сохраняются.
